각 참가자의 초기 비밀번호는 1111입니다. 참가자가 첫 로그인 시 직접 새 번호로 변경합니다.

      
공통통장 설정

      
기존 v2~v9 JSON 가져오기
사진도 Supabase에 업로드하고, 같은 ID는 중복 저장하지 않습니다. 기존 파일에 포함된 사용자 비밀번호는 가져오지 않습니다.

      
전체 데이터 백업
전체 경비·계좌·정산 상태와 첨부 사진까지 하나의 JSON 파일로 다운로드합니다. 민감한 정보가 포함되므로 안전하게 보관하세요.

      

        
⚠ 테스트 정산 데이터 초기화 (문호원 전용)

        
경비 내역·공통통장 잔액·정산 완료 표시를 0으로 초기화합니다. 7명 계정과 비밀번호, 환급 계좌는 유지됩니다. 증빙 사진 파일도 삭제하지 않습니다.

        
초기화 직전의 전체 공유 JSON을 Supabase DB의 q7_backups에 먼저 저장합니다. 백업에 실패하면 초기화를 실행하지 않습니다.
